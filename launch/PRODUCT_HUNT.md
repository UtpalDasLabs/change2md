# Change2MD — Product Hunt launch

## Product URL

https://change2md.utpaldas.com/

## Tagline

Files and webpages to Markdown for any AI

## Description

Convert files and public webpages to clean Markdown for any AI chat, harness or
model through MCP, web, API, CLI and SDK interfaces.

## Launch tags

- Open Source
- Developer Tools

## Pricing

Free and open source.

## Key benefits

- Use the web converter with no account, or connect Change2MD through MCP.
- Build with the REST API, CLI, Python SDK, TypeScript SDK or Chromium extension.
- Convert PDF, Word, PowerPoint, Excel, Outlook, HTML, CSV, JSON, XML, EPUB,
  ZIP, text and public webpages.
- Cloud files are processed temporarily and deleted after conversion.
- The Local edition keeps sensitive-file conversion on the user's computer.
- Powered by Microsoft MarkItDown; independent of Microsoft and OpenAI.

## Maker comment

I built Change2MD because useful AI workflows still get slowed down by file
formats. The content is already there, but first you have to extract it, clean
it up and make it portable.

Change2MD turns documents and public webpages into clean Markdown, then lets you
choose how to use it: a no-account web converter, MCP inside a compatible AI
client, a REST API, CLI, Python or TypeScript SDK, or a Chromium extension.

Privacy was a product decision, not a footnote. Cloud uploads are temporary and
deleted after conversion. For sensitive files, the Local edition runs the
conversion on your own computer. There is no permanent document storage and no
document content in download analytics.

The project is open source and powered by Microsoft MarkItDown. This v0.2.0
release deliberately stays focused: no scanned-document OCR, audio transcription,
recursive crawling, login-protected pages or private-network access.

I would love feedback on conversion fidelity, missing workflows and the file
types you use most often.
