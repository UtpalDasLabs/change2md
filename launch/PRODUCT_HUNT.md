# Change2MD — Product Hunt launch draft

## Tagline

Turn files and webpages into Markdown inside ChatGPT.

## Short description

Choose your privacy level. Install Change2MD Cloud once and ask ChatGPT
naturally, or run Change2MD Local on your own computer for on-device conversion.
Neither edition requires an app mention.

## Key benefits

- Works from ordinary ChatGPT prompts—no special command or `@` mention.
- Handles PDF, Word, PowerPoint, Excel, Outlook, HTML, CSV, JSON, XML, EPUB,
  ZIP, text, and public webpages.
- **Cloud Edition:** effortless ChatGPT web, desktop, and mobile use; files are
  processed temporarily on hosted infrastructure and deleted after conversion.
- **Local Edition:** files are converted on the user's computer through an MCP
  desktop client; no Change2MD cloud upload.
- Open source and powered by Microsoft MarkItDown.

## Maker comment

I built this because converting a file to Markdown should not require leaving
the conversation or remembering a special command. Change2MD Cloud is the easy
one-click option for ChatGPT. Change2MD Local is the privacy-first option for
people willing to install a desktop runtime. Both respond to ordinary requests.

The first release is intentionally focused: deterministic conversion, strict
file and network limits, and no permanent document storage. It does not include
OCR, audio transcription, recursive crawling, or login-protected pages yet.

I would especially value feedback on conversion fidelity and the file types
people use most often.
