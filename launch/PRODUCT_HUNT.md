# Change2MD — Product Hunt launch draft

## Tagline

Turn files and webpages into Markdown inside ChatGPT.

## Short description

Install once, then ask naturally. The plugin automatically converts supported
attachments and public webpages to clean Markdown without requiring an app
mention, separate upload site, or permanent document storage.

## Key benefits

- Works from ordinary ChatGPT prompts—no special command or `@` mention.
- Handles PDF, Word, PowerPoint, Excel, Outlook, HTML, CSV, JSON, XML, EPUB,
  ZIP, text, and public webpages.
- Privacy-minded: temporary processing, no accounts, no permanent file storage.
- Open source and powered by Microsoft MarkItDown.

## Maker comment

I built this because converting a file to Markdown should not require leaving
the conversation or remembering a special command. Install the plugin once,
attach a supported file or paste a public URL, and ask ChatGPT normally.

The first release is intentionally focused: deterministic conversion, strict
file and network limits, and no permanent document storage. It does not include
OCR, audio transcription, recursive crawling, or login-protected pages yet.

I would especially value feedback on conversion fidelity and the file types
people use most often.
