# Change2MD distribution checklist

## Primary

- OpenAI universal Plugin Directory (ChatGPT and Codex)
- Product Hunt
- Public GitHub repository with GitHub Pages

## After approval

- Hacker News `Show HN`
- Reddit communities where self-promotion is allowed
- LinkedIn launch post
- X launch thread
- Dev.to or Hashnode technical write-up
- MCP Registry, if its current submission rules accept the hosted server

Each community post should be adapted to its rules and published only after the
OpenAI review is approved and the public endpoint is stable.
