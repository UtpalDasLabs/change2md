Privacy Policy

How Change2MD Cloud and Local handle data.

Two editions

Change2MD Cloud uses hosted Vercel infrastructure. Change2MD Local runs Microsoft's MarkItDown MCP server on the user's own computer and does not send local file contents to Change2MD's cloud. A user's MCP client or model provider may process prompts, tool arguments, or results under that provider's own terms.

Cloud data processed

When you request a Cloud conversion, Change2MD receives the file or public URL needed for that request. It processes the content to produce Markdown. The service may also receive ordinary technical request data, such as timestamps, network addresses, response status, and user-agent information, through its hosting infrastructure.

Purpose and retention

Submitted Cloud content is used only to perform the requested conversion and enforce service security limits. Files are stored temporarily during processing and deleted when conversion finishes or fails. Change2MD does not provide accounts or permanent document storage. Hosting providers may retain limited technical logs under their own operational and security policies.

Sharing

Cloud content is processed by the infrastructure needed to operate Change2MD and by Microsoft MarkItDown software. Change2MD does not sell submitted content or use it for advertising. Public webpage requests necessarily contact the destination website.

Your choices

Use the Local Edition when you do not want local document contents sent to Change2MD's hosted service. Do not submit confidential, regulated, or sensitive content to Cloud unless your use is authorized and appropriate. Because document content is not permanently stored, there is ordinarily no retained Cloud document copy to retrieve or delete after a request completes.

Contact

For privacy questions, open a privacy-labeled issue in the public repository without including personal or confidential content.
