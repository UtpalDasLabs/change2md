Support

Help with Change2MD Cloud and Local.

Before reporting a problem

For Cloud, confirm the file is under 25 MB and the request is for a supported format or one public HTTPS URL. Private-network and login-protected URLs are intentionally blocked. For Local, confirm uvx --version works and the desktop client can see the convert_to_markdown tool. See the Local setup guide.

Get help

Open a public issue in the Change2MD GitHub repository. Do not attach confidential files, credentials, personal data, or private URLs. Include only a safe sample, the edition, file type, and error message.
