Support

Help with Change2MD.

Before reporting a problem

Confirm the file is under 25 MB and the request is for a supported format or one public HTTPS URL. Private-network and login-protected URLs are intentionally blocked.

Get help

Open a public issue in the Change2MD GitHub repository. Do not attach confidential files, credentials, personal data, or private URLs. Include only a safe sample, the file type, and the error message.
